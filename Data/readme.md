
## Data ## 

This directory contains the data files used in the study.

Files
|File | Description |
| --- | ------------|
| Group1-Models.RData	| Literature where the focus are the models |
| Group2-Aplications.RData | Literature where the focus are applications of the models |
| Group3-Datasets.RData	| Literature related to building datasets |
| Group4-TL-SD.RData | Literature related to transfer learning or to the use of synthetic data |
| Scopus_Bibliometrix-Export-File.RData | Exported data from Scopus |
| WoS_Bibliometrix-Export-File.RData | Exported data from Web of Science |
| Selected_Pub_Bibliometrix-Export-File.RData | Selected publications for the analysis |
